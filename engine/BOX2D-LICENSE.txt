engine/src/box2d/box2d.ts is an ALTERED VERSION of Box2DFlash 2.0.2: the
ActionScript 3 that shipped inside the original game was machine-translated to
TypeScript by tools/as3_to_ts.py, with Math.sin/cos/atan2 replaced by the
deterministic versions in engine/src/box2d/dettrig.ts. It is not the original
software. The notice lives in this file rather than at the top of box2d.ts
because the engine's build version is a hash of that directory.
